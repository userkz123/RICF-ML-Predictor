# Изменения этой сборки
- Сохранены главные вкладки и обученные модели.
- Переработана страница Probabilistic Forecasting: ручной ввод + CSV, график по контрольным датам, результаты в единой валюте, экспорт.
- Категория проекта выбирается строго из категорий обучающей базы; общая Construction больше не проходит незаметно.
- Проверяются пропуски, отрицательные/нулевые значения, дубликаты, монотонность EV/PV/AC, сохранение BAC.
- Номинальные интервалы 80/90% имеют историческую калибровку; нижний край не меньше фактических затрат AC.
- Добавлен редактируемый реестр нескольких рисков; Monte Carlo рассчитывается отдельно без автоматического суммирования с ML EAC.
- Из заголовков удалены слова synthetic/simulated/hypothetical; внутри сохранены разъяснения об искусственном происхождении кейсов и ограничениях проверки.
- Подготовлены файл конфигурации, зависимости и инструкции для Streamlit Community Cloud.
- Историческая модель НЕ переобучалась; статистическая точность не изменилась.
