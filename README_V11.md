# RICF-ML v11 — Synthetic Portfolio Demonstration

Install dependencies: `pip install -r requirements.txt`
Launch: `streamlit run app.py`
Open the page **Portfolio Experiment v11** in the sidebar.

Files: `portfolio_synthetic_checkpoints.csv`, `portfolio_illustrative_predictions.csv`, `portfolio_risk_register.csv`, `portfolio_policy_comparison.csv`, `portfolio_simulation_draws.csv`, `V11_RESEARCH_REPORT.md`.

**All company data and risks are synthetic. The ML model is pretrained on DSLIB candidate projects and is not trained on company examples. Never interpret these generated cases as external model validation.**
