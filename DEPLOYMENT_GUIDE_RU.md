# Публикация RICF-ML в Streamlit Community Cloud

1. Создайте аккаунт на https://github.com и репозиторий (для простоты — публичный). Не загружайте конфиденциальные проектные данные или секреты. Перед загрузкой проверьте права на публикацию исторической базы DSLIB и лицензии.
2. Загрузите **содержимое** этой папки в корень репозитория, включая `app.py`, `requirements.txt`, `pages/`, модель `.joblib` и необходимые CSV/SQLite. ZIP как один файл загружать недостаточно.
3. Откройте https://share.streamlit.io и подключите GitHub.
4. Нажмите **Create app**, выберите репозиторий, ветку `main` и main file path `app.py`.
5. В дополнительных настройках выберите Python 3.12, затем Deploy. После успешного запуска получите адрес вида `https://<имя>.streamlit.app`.
6. Откройте ссылку на другом устройстве. Проверьте страницы, CSV-загрузку, вывод прогнозов и сценарные расчёты.

Важно: `localhost:8501` доступен только локально. Публикация не происходит автоматически при запуске кода на Mac. Изменения в GitHub применяются к развернутому приложению. Не используйте приложение для конфиденциальной финансовой информации без оценки защиты данных. Поддерживаемые версии пакетов могут влиять на совместимость сохранённых моделей: при ошибке загрузки нужно воспроизвести окружение обучения.
